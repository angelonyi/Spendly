# Personal Expense Tracker

A web application for recording personal expenses, tracking monthly spending, and managing budgets across multiple currencies.

### Features
- Create and manage expenses.
- View monthly spending summaries.
- Organize expenses by category.
- Set monthly budgets and monitor spending.
- Support NGN, USD, GBP, and EUR without automatic currency conversion.

### Technology
- Next.js
- TypeScript
- CSS design tokens

Prisma and PostgreSQL are part of the planned technology stack; confirm their integration before listing them as implemented technologies.
